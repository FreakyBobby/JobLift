# Joblyft - Job Search Platform

A modern job search and recruitment platform built with HTML, CSS, and JavaScript.

## Project Structure

```
joblyft/
├── assets/
│   └── images/         # Image assets
├── css/               # Stylesheets
│   ├── styles.css     # Global styles
│   ├── login.css      # Login page styles
│   ├── register.css   # Registration page styles
│   └── ...
├── js/                # JavaScript files
│   ├── login.js       # Login functionality
│   ├── register.js    # Registration functionality
│   └── ...
├── pages/             # HTML pages
│   ├── index.html     # Home page
│   ├── login.html     # Login page
│   ├── register.html  # Registration page
│   └── ...
└── README.md          # Project documentation
```

## Features

- User authentication (login/register)
- Job search and filtering
- Job posting for employers
- Responsive design
- Modern UI/UX

## Setup

1. Clone the repository
2. Open any HTML file in a web browser to view the pages
3. No build process required - this is a static website

## Technologies Used

- HTML5
- CSS3
- JavaScript (ES6+)
- Font Awesome for icons
- Google Fonts (Poppins)

## Browser Support

- Chrome (latest)
- Firefox (latest)
- Safari (latest)
- Edge (latest)
